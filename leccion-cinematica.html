Módulo 3 · Cinemática del brazo

Del espacio cartesiano (X, Y, Z) a los ángulos de las articulaciones: la matemática que hace que el robot llegue donde le indicas.

3 Lecciones
90 min Duración
2 Prácticas 3D
1 Quiz final

Antes de mover nada, necesitas entender dónde vive el robot. Todo movimiento que le ordenes se mide desde un punto fijo llamado origen, con coordenadas (0, 0, 0).

¿Dónde está el origen en el Magician Lite?

En la base del brazo: el punto donde arranca la rotación del pedestal. Desde ahí se definen tres ejes:

  • X — apunta hacia el frente del robot (donde él "mira" al encenderse)
  • Y — apunta hacia la izquierda del robot
  • Z — apunta hacia arriba, perpendicular a la mesa
Por qué importa: cuando ordenes ptp(x=200, y=0, z=100), el robot entenderá "200 mm al frente, 0 a los lados, 100 mm de altura". Si confundes los ejes, el brazo irá al lugar equivocado — o intentará atravesar la mesa.

Regla mnemotécnica

Piensa en un misterio de detective: el robot siempre "mira al frente (+X), escucha a su izquierda (+Y) y salta hacia arriba (+Z)".

Verlo en el modelo 3D Abre el visor y observa los ejes de colores sobre la base

El mismo movimiento del brazo puede describirse de dos formas. Dominar ambas es la diferencia entre operar un robot y programarlo.

Lenguaje articular (J1, J2, J3, J4)

Habla de ángulos de cada articulación. Es como darle instrucciones a tu propio brazo: "sube el hombro 30°, dobla el codo 45°". 

J1 (base)   = 45°     → giró 45° hacia la derecha
J2 (hombro) = 30°     → elevó el brazo
J3 (codo)   = -45°    → dobló el antebrazo
J4 (muñeca) = 0°      → herramienta recta

Lenguaje cartesiano (X, Y, Z)

Habla de una posición en el espacio. Es como pedirle "pon la punta en este punto exacto". El robot calcula solo los ángulos. 

X = 200 mm   → 200 mm al frente
Y = 0 mm     → centrado
Z = 150 mm   → 150 mm sobre la mesa

Las dos direcciones de la cinemática

Dirección Entrada → Salida ¿Quién lo hace?
Cinemática directa (CD) Ángulos → Posición El visor 3D: mueves los sliders y el panel muestra X, Y, Z
Cinemática inversa (CI) Posición → Ángulos El laboratorio MATLAB: escribes ptp(x, y, z) y el robot llega
Dato de ingeniería: la CI no tiene siempre una única solución — un brazo de 2 eslabones iguales (L1 = L2 = 150 mm) puede llegar al mismo punto con el codo "hacia arriba" o "hacia abajo". Elegir una se llama configuración del brazo.
Practicar CD con sliders

Aquí está la matemática real que ejecuta tu plataforma cuando escribes ptp(x, y, z). Es la misma fórmula programada en el código del simulador — no es magia, es trigonometría.

Paso 1 · Simplificar el problema

La rotación de la base (J1) es independiente: solo depende de a qué lado apuntar. Los otros dos ángulos (hombro y codo) se resuelven en el plano vertical que contiene al brazo: 

θ1 (base)  = atan2(Y, X)
     → ángulo hacia el objetivo en el plano del piso

r = √(X² + Y²)        → distancia horizontal al objetivo
dz = Z - 107          → altura RELATIVA al hombro
     (el hombro está a 107 mm del suelo)

Paso 2 · El triángulo del brazo

El hombro, el codo y el objetivo forman un triángulo donde:

  • Lado a = L2 = 150 mm (antebrazo)
  • Lado b = L1 = 150 mm (brazo)
  • Lado c = d = distancia al objetivo

Con la ley de cosenos despejamos el ángulo del codo: 

cos(θ3_int) = (L1² + L2² − d²) / (2 · L1 · L2)

θ3_int = acos( cos(θ3_int) )     → ángulo interior del codo

Paso 3 · El ángulo del hombro

φ   = atan2(dz, r)                        → inclinación del objetivo
β   = acos( (L1² + d² − L2²) / (2 · L1 · d) )

θ2   = φ + β          → configuración "codo abajo"

Ejemplo numérico completo

Lleva el efector a X=200, Y=0, Z=150:

r   = √(200² + 0²)              = 200 mm
dz  = 150 − 107                 = 43 mm
d   = √(200² + 43²)             = 204.6 mm

θ1  = atan2(0, 200)             = 0°

cos(θ3) = (150² + 150² − 204.6²) / (2·150·150)
        = (22500 + 22500 − 41861) / 45000
        = 0.0709...              → θ3_int = 85.9°

φ   = atan2(43, 200)            = 12.1°
β   = acos((150² + 204.6² − 150²)/(2·150·204.6)) = 61.8°

θ2  = 12.1 + 61.8               = 73.9°

✅ Resultado: J1=0°, J2=73.9°, J3=−85.9°
Verifícalo tú mismo: abre el visor 3D, coloca los sliders en J2=73.9° y J3=−85.9° y observa que la punta apunta cerca de X=200, Z=150. Si coincide — acabas de validar la cinemática del robot real con papel y lápiz.

¿Y si el objetivo está fuera de alcance?

Si d > L1 + L2 (aquí 300 mm), el punto es inalcanzable: no existe triángulo. El simulador te lo avisa — en el robot físico, el brazo se estiraría forzando los motores. Por eso siempre se valida el espacio de trabajo antes de ejecutar.

Probar en MATLAB: ptp(200, 0, 150, 0)
